## 🌟 Key Features & Enhancements

* 🔍 **Interactive Project Search & Filter:** 
  Allows users to dynamically search and filter through portfolio projects in real time by **title**, **description**, **technologies**, or **keywords**.

* 🌤️ **Live Weather Checker:** 
  Integrates a real-time weather tool providing current meteorological data for any queried city, including exact **temperature (°C)**, **sky conditions** (e.g., clear skies, clouds), and **humidity levels**.

* 🤖 **Ask My AI Assistant:** 
  Includes an embedded AI-powered chatbot widget designed to answer user inquiries about skills, projects, and professional background interactively.

* 🌗 **Modern Floating Theme Toggle:** 
  Features a floating, pill-shaped light/dark mode switch with dynamic icon transitions (`☀️` Light / `🌙` Dark) and persistent state management via `localStorage`.

* ✨ **Enhanced Modern UI/UX:** 
  Upgraded visual aesthetics with hardware-accelerated card hover animations, smooth transitions, refined typography, a structured Contact card, and a centered professional copyright footer.
